Temporal Audio Language and Images

TALI is a multimodal dataset linking Wikipedia photographs, captions and articles to clips from YouTube recordings, their sound and available timed subtitles. A single reference image can lead to two different recordings.

Watching the stored video end to end would take about 56 weeks (12.9 months). The release links 143,250 recordings to 105,544 Wikipedia image–text entries.

Each example runs independently on a CPU and reads a small slice of a fixed public release.

Read a clip and save its Wikipedia reference image

Open the first training clip. Requesting just three Parquet columns lets you read the image, recording title and starting time without fetching the video column.

from io import BytesIO

import pyarrow.parquet as pq
from huggingface_hub import HfFileSystem
from PIL import Image

release = "753b14068682ac5fdf3de47dc1b695bc8f26331d"
shard = "data/train-00000-of-00600-e9123a82b71a4590.parquet"
path = f"datasets/Antreas/TALI@{release}/{shard}"
columns = ["image", "youtube_title_text", "youtube_video_starting_time"]

with HfFileSystem(token=False).open(path, "rb", block_size=65_536) as source:
    group = pq.ParquetFile(source).read_row_group(0, columns=columns)
    clip = group.slice(0, 1).to_pylist()[0]

with Image.open(BytesIO(clip["image"]["bytes"])) as photo:
    photo.save("tali-reference.png")
print(clip["youtube_title_text"])
print(f'{clip["youtube_video_starting_time"]} seconds into the recording')

You get tali-reference.png and “Shintomicho Station, Tokyo Subway Neighborhood” at 18:00. Open this clip in the visualizer →

Read the text vector for a subtitle window

Use the field column to select subtitle text, YouTube titles, descriptions or individual Wikipedia text fields. The subtitle input includes the recording title and available cues starting in the clip’s first ten seconds.

from datasets import load_dataset

views = load_dataset(
    "Antreas/TALI-gemma-embedding-2-vectors",
    "vectors",
    revision="a5f6d5646229ca5009fd3d0b7e571b0391181ef5",
    data_files={"train": "vectors/train/part-0010.parquet"},
    split="train",
    streaming=True,
    filters=[("field", "=", "subtitle_window")],
    columns=["source_shard", "source_row", "field", "embedding"],
    token=False,
)
subtitle = next(iter(views))
print(subtitle["field"], len(subtitle["embedding"]))
print(subtitle["source_shard"], subtitle["source_row"])

The first match prints subtitle_window 768. Its source_shard and zero-based source_row point to the Tokyo clip at row 0 of the original training shard.

Find a video window using a stored title vector

Compare the Tokyo title with 74 other video windows in the first two Parquet row groups of one part. The query clip is excluded. The vectors have unit length, so their dot product gives cosine similarity.

import numpy as np
import pyarrow.parquet as pq
from huggingface_hub import HfFileSystem

fs = HfFileSystem(token=False)
snapshot = "a5f6d5646229ca5009fd3d0b7e571b0391181ef5"
vectors = f"datasets/Antreas/TALI-gemma-embedding-2-vectors@{snapshot}"
columns = ["source_shard", "source_row", "view", "field", "embedding"]

part = f"{vectors}/vectors/train/part-0010.parquet"
with fs.open(part, "rb", block_size=65_536) as file:
    groups = pq.ParquetFile(file).read_row_groups([0, 1], columns=columns)
    sample = groups.to_pylist()

title = next(r for r in sample if r["field"] == "youtube_title_text")
# Omit the query clip itself.
query_id = (title["source_shard"], title["source_row"])
gallery = [
    r for r in sample
    if r["view"] == "video" and (r["source_shard"], r["source_row"]) != query_id
]
video = np.asarray([r["embedding"] for r in gallery], dtype="float32")
scores = video @ np.asarray(title["embedding"], dtype="float32")
i = int(scores.argmax())
match = gallery[i]

# Look up the shard first, then the zero-based row within it.
release = "753b14068682ac5fdf3de47dc1b695bc8f26331d"
source = f'datasets/Antreas/TALI@{release}/{match["source_shard"]}'
with fs.open(source, "rb", block_size=65_536) as file:
    columns = ["youtube_title_text", "youtube_video_starting_time"]
    metadata = pq.ParquetFile(file).read(columns=columns)
clip = metadata.slice(match["source_row"], 1).to_pylist()[0]
print(f'Top of {len(gallery)} candidate clips: cosine {scores[i]:.3f}')
print(clip["youtube_title_text"], clip["youtube_video_starting_time"])

The nearest window is from the same recording at 25:00, with cosine 0.654. The example uses the returned shard and row to look up that timestamp in the original dataset. Open the matching clip →
